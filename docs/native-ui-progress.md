# Native UI refinement progress

Waypoints borrows Delta’s compact integrated toolbar, persistent sidebar boundary, short left-aligned rows, disclosure chevrons, and contextual secondary actions. The sidebar remains a project/workflow hierarchy. Folder basenames get a parent qualifier when needed, and full paths are available in tooltips. macOS traffic lights share the title row with Add Project and the sidebar toggle. Settings opens separately through the application menu or Command-comma. System, Light, and Dark use the existing atomic preference writer.

The workspace uses independent project loading, retry, and removal. Loading and empty states are inline, and missing folders have a distinct status. Restored selections report that they are reopening or direct the user to Retry. Duplicate-folder and picker notices can be dismissed. Project removal changes the sidebar and leaves its folder and backend data available. Workflow operations use the backend client.

Native QA used a disposable backend and preferences under the directory recorded in /tmp/wp-ui-current. The Waypoints Interactive QA bundle carries isolated launch environment values in Info.plist. The native checks covered same-named folders, long labels, keyboard focus and selection, project disclosure and menus, removal, Add Project deduplication, backend failure, missing-folder recovery, empty and loading states, 720 × 480 scroll and divider drag, sidebar toggle, zoom, appearance changes, and quit/relaunch restoration. The duplicate notice was dismissed in the latest build. The before and after app-window captures are in the chat. The baseline captures used the same window dimensions but differed in appearance. The final dark Waypoints capture matches the Delta reference at 2880 × 1738 pixels. Standalone screenshot files were not exported.

Rendered tests exercise settings, disclosure and removal, sidebar keyboard navigation, Retry isolation, and scrolling at minimum size. The final workspace suite, strict app Clippy, formatting, and diff checks passed. Preserve pending workspace, persistence, hot reload, and vendor work. No commit or push was requested.
